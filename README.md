# Chris — AI Engineer Portfolio

A clean, responsive personal portfolio built with React and Vite. It introduces Chris, presents his current technical toolkit, and documents his work without overstating its stage.

## Featured work

- **Sinéfolis** — an early multi-page cinema frontend built with HTML, CSS, and JavaScript.
- **Voice-Controlled Media Assistant** — a native Android concept for hands-free media playback using Java, Android SDK, SpeechRecognizer, MediaSessionManager, MediaController, and a foreground service.
- **[Vehicle Detection for Traffic Light Optimization](docs/vehicle-traffic-vision.md)** — an academic team prototype using Python, OpenCV MOG2, NumPy, frame-relative ROI masking, morphological filtering, centroid tracking, and bounded green-time logic. Chris contributed the system architecture, ROI and MOG2 layers, and presentation design. [View the canonical team repository](https://github.com/Jozioo/Vehicle-Detecion---MOG).

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The optimized output is generated in `dist/`.
